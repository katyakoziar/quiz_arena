# Quiz Arena — вікторина в реальному часі

Простий аналог Kahoot: один пристрій — хост, інші підключаються за PIN-кодом
з телефону чи ноутбука. Синхронізація — через WebSocket (Socket.io), сервер
на Node.js. Ніякої бази даних, ніякої реєстрації — все в пам'яті процесу.

Фронтенд — один HTML-файл (React + Babel прямо в браузері з CDN), тому
**збірка (build) не потрібна взагалі**.

---

## 1. Запуск локально (перевірити, що все працює)

Потрібен лише встановлений [Node.js](https://nodejs.org) версії 18+.

```bash
npm install
npm start
```

Відкрити у браузері: **http://localhost:3000**

Щоб перевірити з кількома "гравцями" — відкрийте ще одну вкладку або
зайдіть з телефону на `http://<IP-адреса-вашого-компʼютера>:3000`
(комп'ютер і телефон мають бути в одній Wi-Fi мережі).

---

## 2. Розгортання онлайн (найпростіший варіант — Render.com)

Потрібен постійний Node-процес (через WebSocket), тому звичайний
статичний хостинг (GitHub Pages тощо) не підійде — а безкоштовний
[Render](https://render.com) підходить ідеально.

### Крок за кроком:

1. Заведіть безкоштовний акаунт на [render.com](https://render.com).
2. Завантажте цю папку у GitHub-репозиторій (або скористайтесь опцією
   Render "Deploy from public Git repository" / "Upload files").
3. У Render натисніть **New → Web Service**.
4. Оберіть цей репозиторій.
5. Налаштування:
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
   - **Instance Type:** Free
6. Натисніть **Create Web Service**.
7. Через 1–2 хвилини Render видасть вам публічну адресу типу
   `https://quiz-arena-xxxx.onrender.com` — це і є ваш сайт. Просто
   надсилайте це посилання гравцям.

> **Примітка:** на безкоштовному тарифі Render "засинає" сервер після
> ~15 хв бездіяльності, і перше відкриття після сну займає ~30–50 секунд.
> Для живої гри з групою людей це не критично — просто відкрийте сайт
> заздалегідь, за хвилину-дві до початку.

### Альтернативи Render (так само просто, той самий підхід "Build/Start command"):
- [Railway.app](https://railway.app)
- [Fly.io](https://fly.io)
- [Cyclic.sh](https://cyclic.sh)
- Будь-який власний VPS (просто `npm install && npm start`, і відкрити порт)

## 3. Як це працює (коротко)

- `server.js` — Express-сервер, який також слухає WebSocket-з'єднання
  (Socket.io). Весь стан гри (PIN, питання, гравці, бали) зберігається
  **в пам'яті сервера**, тому й перезапуск сервера скидає всі активні ігри.
- `public/index.html` — весь інтерфейс (вибір ролі, створення вікторини,
  лобі, ігровий процес, лідерборд, фінал) в одному файлі, без збірки.
- Бали нараховуються на сервері (500 базових + до 500 бонусу за швидкість
  відповіді) — це надійніше за підрахунок на клієнті, бо гравець не може
  підмінити свій результат.
- Правильна відповідь передається гравцю лише **після** того, як він
  відповів або час вийшов — до того моменту вона гравцю не видима навіть
  через інструменти розробника в браузері.

## 4. Обмеження (навмисно спрощено, як і просилося в ТЗ)

- Немає бази даних — історія ігор не зберігається між перезапусками сервера.
- Немає авторизації.
- Немає захисту від кількох вкладок одного гравця.
- Немає зображень/відео у питаннях — лише текст.

Якщо ці функції знадобляться пізніше — legko додати (наприклад, підключити
[Postgres](https://render.com/docs/databases) на тому ж Render для
збереження історії ігор).
